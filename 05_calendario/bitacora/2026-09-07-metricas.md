## Paso 0 — por qué `metricas.json` está parado, y qué es retraso y qué es fallo

Las dos causas están escritas hoy en `05_calendario/bitacora/2026-09-07-direccion.md`
y en el propio código, y son dos cosas distintas:

1. **Choque de horarios (ya corregido, pero llegó tarde para hoy).** Esta
   tarea corría a las 07:00 UTC, entre los dos intentos de `metricas.yml`
   (05:19 y 08:37). El intento 1 de hoy se retrasó — a las 07:27 UTC seguía
   sin `commit` — así que a las 07:00 no había nada nuevo que leer. El
   arreglo (mover esta tarea a las 10:00 UTC) es correcto para las semanas
   que vienen, pero **hoy no era la causa de fondo**.
2. **Ámbitos de OAuth — esta es la causa real de hoy, con estas palabras:**
   el token vigente (regenerado el 01/09) se concedió sin `yt-analytics.readonly`,
   así que al refrescar con la lista completa de ámbitos Google devolvía
   `invalid_scope: Bad Request` y `metricas.py` moría entero — incluida la
   parte que no necesita analítica (la corrección del registro de
   publicaciones). Los dos intentos de hoy (05:19 y 08:37 UTC) corrieron
   **antes** de que el arreglo se subiera a `origin/main` (commit `82a799f`,
   09:22 UTC / 11:22 hora de España): los dos fallaron con el código viejo.

   `metricas.py` y `obtener_token_youtube.py` ya están corregidos en
   `origin/main`, pero **el arreglo de código no repara el token**: evita el
   `invalid_scope` y hace la parte de Data API aunque falte el ámbito de
   analítica, y avisa en castellano — no hace aparecer visualizaciones de la
   nada. Mientras el `refresh token` guardado en el secreto de GitHub siga
   sin `yt-analytics.readonly`, cualquier relanzamiento **seguirá sin traer
   números de analítica**, aunque ya no rompa. En la bitácora de dirección de
   hoy, punto 3 de «Pendiente del codirector», sigue abierto: **regenerar el
   token con las tres casillas marcadas**. Hasta que eso pase, relanzar
   `metricas.yml` a mano (Actions → «Leer métricas» → *Run workflow*) confirma
   que el código ya no se cae, pero no trae una lectura nueva. En cuanto el
   token tenga el ámbito, ese mismo relanzamiento sí la trae, y esta lectura
   se puede repetir el mismo día.

**Una semana perdida es una semana perdida de verdad para C26**, así que hago
con lo que hay el resto de esta bitácora en vez de parar aquí.
